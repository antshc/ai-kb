= Scenarios: Exploring LLM Behavior with Different Prompt Types

The following scenarios demonstrate how different prompt styles and input formats influence the responses generated by a Large Language Model (LLM).  
Each scenario uses the same task: *generate a healthy carrot-based recipe (high-protein / low-carb)* but varies the **prompt structure and format**.

== Scenario 1: Baseline Instruction vs Minimal Prompt

Goal::
Evaluate how response quality changes when the model receives detailed instructions versus a minimal prompt.

Prompts Used::
- Standard Instruction Prompt (Baseline)
- Compact Prompt (Minimal Prompt)

Steps::
1. Run the *Standard Instruction Prompt*.
2. Record the generated recipe.
3. Run the *Compact Prompt*.
4. Record the generated recipe.
5. Compare both outputs.

Evaluation Criteria::
- Completeness of the recipe
- Accuracy of nutritional information
- Structure and readability
- Level of detail in instructions

Expected Observation::
The baseline prompt usually produces a more structured and complete response, while the minimal prompt may generate shorter, less consistent outputs.

== Scenario 2: Persona Prompt vs Chain-of-Thought Prompt

Goal::
Explore how reasoning instructions affect the structure and explanation of the generated recipe.

Prompts Used::
- Role + Goal Prompt (Persona Style)
- Step-Reasoning Prompt (Chain-of-Thought)

Steps::
1. Run the *Role + Goal Prompt*.
2. Observe how the model generates the recipe from the perspective of a chef and nutritionist.
3. Run the *Chain-of-Thought Prompt*.
4. Observe how the model reasons about protein sources, cooking techniques, and nutritional balance before producing the recipe.

Evaluation Criteria::
- Presence of reasoning steps
- Nutritional justification
- Logical structure of the recipe design
- Ingredient choices

Expected Observation::
The Chain-of-Thought prompt typically results in more analytical outputs and clearer reasoning about ingredient selection.

== Scenario 3: Structured Output vs Example-Driven Prompt

Goal::
Evaluate how output format constraints influence response consistency.

Prompts Used::
- Structured JSON Prompt
- Few-Shot Prompt (Example-Based)

Steps::
1. Run the *Structured JSON Prompt*.
2. Validate whether the output strictly follows the requested JSON schema.
3. Run the *Few-Shot Prompt* containing the example recipe.
4. Compare how closely the generated recipe follows the provided example format.

Evaluation Criteria::
- Output structure consistency
- Ease of machine parsing
- Similarity to example patterns
- Content richness

Expected Observation::
The JSON prompt tends to produce highly structured outputs suitable for automation, while the Few-Shot prompt often generates more natural and stylistically similar recipes to the provided example.

== Conclusion

By comparing these scenarios, it becomes possible to understand how different prompt engineering techniques influence:

- Output structure
- Response quality
- Level of reasoning
- Consistency and formatting

These insights help determine the most effective prompt design strategy depending on whether the goal is **human readability, reasoning transparency, or machine-parsable structured data**.
