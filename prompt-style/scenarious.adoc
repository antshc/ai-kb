= Scenarios: Exploring LLM Behavior with Different Prompt Types

The following scenarios demonstrate how different prompt styles and input formats influence the responses generated by a Large Language Model (LLM).  
Each scenario uses the same task: *generate a healthy carrot-based recipe (high-protein / low-carb)* but varies the **prompt structure and format**.

== Scenario 1: Work with image
1. Upload image with carrot
2. Run Prompt
[source,text]
----
Create a recipe with the vegetable from an image are one of the main ingredients.
----

== Scenario 2: Work with image
1. Upload image with carrot
2. Upload a pdf with recipe
3. Run Prompt
[source,text]
----
Create a recipe with the vegetable from an image are one of the main ingredients from the pdf recipe book.
----

== Scenario 2: Prompt styles

Goal::
Evaluate how response quality changes when the model receives different prompt styles.
Minimal Prompt, Constraints Prompt, chain of thoughts.

Minimal Prompt (Baseline)
[source,text]
----
Create a healthy recipe where carrots are one of the main ingredients.
----

Constraints Prompt 
[source,text]
----
Create a healthy high-protein, low-carb recipe where carrots are one of the main ingredients.

Avoid refined carbohydrates.
Use lean protein sources and healthy fats.
Include cooking steps, ingredients, cooking time, and nutrition information.
----

Step-Reasoning Prompt (Chain-of-Thought)::
[source,text]
----
You are a chef and nutrition expert.

Task:
Create a healthy recipe that is high in protein and low in carbohydrates.

First:
1. Analyze what is banana
2. Identify what it main flavour characteristics what makes the dish spicy and hot.
3. Explain what it uniqueness for cooking

Second:
1. Identify suitable protein sources.
2. Choose cooking techniques that preserve nutrients.
3. Combine the fruit or vegetable from `first` with protein and healthy fats.

Than produce a detailed recipe suitable for a home cook in the output format below.

Output format:
1. Recipe title
2. Short description
3. Ingredients with metric quantities
4. Step-by-step instructions
5. Cooking time and temperature
6. Nutrition estimate per serving (protein, carbs, fat, calories)
7. Tips to improve healthiness
8. Optional variations
----

Evaluation Criteria::
- Completeness of the recipe
- Accuracy of nutritional information
- Structure and readability
- Level of detail in instructions

Expected Observation::
The baseline prompt usually produces a more structured and complete response, while the minimal prompt may generate shorter, less consistent outputs.
