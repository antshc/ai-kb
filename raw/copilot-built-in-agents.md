# GitHub Copilot built-in agents

- **explore** — Investigates a codebase or topic without changing files. Useful for understanding structure, dependencies, flows, and implementation options.
- **task** — Executes development tasks such as builds, tests, linters, formatters, and dependency commands. Useful for validating changes and summarizing command output.
- **general-purpose** — Handles broad implementation, explanation, and troubleshooting work when no specialized agent is a better fit.
- **code-review** — Reviews code changes for real issues such as bugs, security problems, race conditions, and logic errors. Focuses on correctness, not style.
- **research** — Performs deeper technical research across the repository, documentation, GitHub, web, APIs, and libraries. Useful for architecture or dependency investigation.
- **rubber-duck** — Helps reason through a problem step by step by asking clarifying questions and reflecting assumptions. Useful for debugging or design thinking before implementation.
