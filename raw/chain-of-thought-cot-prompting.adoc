= Chain-of-Thought (CoT) Prompting

== What It Is
Chain-of-Thought (CoT) prompting means asking the model to reason step by step, similar to how a human would solve a problem.

It improves clarity, structure, and reliability in complex tasks.

== Why Use CoT?

* Improves accuracy in logic, math, and multi-step tasks
* Makes reasoning clearer and easier to debug
* Produces more structured and predictable outputs
* Helps with automation and agent-based workflows

== Three Levels of CoT

=== 1. Basic CoT

Add a simple instruction like:

----
Think step by step.
----

* Fast and minimal
* Good for quick reasoning improvements

=== 2. Guided CoT

Explicitly define the reasoning steps.

Example:

----
1. Understand the problem
2. Identify constraints
3. Evaluate possible solutions
4. Provide final answer
----

* Better for structured analysis
* Improves consistency

=== 3. Structured CoT

Use structured tags to separate reasoning sections.

Example:

----
<context>Problem background</context>
<analysis>Step-by-step reasoning</analysis>
<answer>Final answer</answer>
----

* Best for applications, agents, automation
* Easy to parse and validate
* Clean separation of reasoning and final output

== Extended Structured CoT Tags

=== Core Reasoning Tags

----
<context>Problem background</context>
<assumptions>Explicit assumptions</assumptions>
<analysis>Detailed reasoning</analysis>
<alternatives>Other possible approaches</alternatives>
<decision>Chosen solution and rationale</decision>
<answer>Final answer</answer>
----

== Easy Recall Formula

Simple → Guided → Structured

Better reasoning → Clear steps → Controlled output

== When to Apply CoT

* Product feedback analysis
* Planning and prioritization
* Code reviews or bug triage
* Architecture design decisions
* Any logic-heavy workflow
