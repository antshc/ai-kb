# Agent Patterns

**Source:** `sources/agent-patterns.md`

## Summary

Agents run one after another. Each step depends on the output of the previous step. ```text Input → Agent A → Agent B → Agent C → Output ``` Use when the task has clear stages. Example: ```text Research → Plan → Implement → Review ``` Good for: - deterministic workflows - step-by
