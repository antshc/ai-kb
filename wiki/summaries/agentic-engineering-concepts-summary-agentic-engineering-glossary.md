# Agentic Engineering Concepts

**Source:** `sources/agentic-engineering-glossary.md`

## Summary

- **Context engineering** Structuring the information an agent receives so it can make better decisions. This includes prompts, retrieved documents, memory, tool outputs, and the current task state. - **ReAct** A workflow in which the agent alternates between reasoning and acting
