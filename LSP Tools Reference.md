# LSP Tools Reference

| Tool | Keyword to run by agent | Description |
|------|--------------------------|-------------|
| LSP | `goToDefinition` | Find where a symbol is defined |
| LSP | `findReferences` | Find all usages of a symbol |
| LSP | `rename` | Semantically rename a symbol across files |
| LSP | `hover` | Get type info and documentation for a symbol |
| LSP | `documentSymbol` | List all symbols in a file |
| LSP | `workspaceSymbol` | Search symbols by name across the workspace |
| LSP | `goToImplementation` | Find implementations of an interface/abstract type |
| LSP | `incomingCalls` | Find what calls a given function |
| LSP | `outgoingCalls` | Find what a given function calls |
